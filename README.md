# SkyShell 🚀

SkyShell, güvenli ve şifreli bir bağlantı üzerinden uzak bilgisayarları izlemek ve yönetmek için tasarlanmış profesyonel bir Uzaktan Yönetim Aracıdır (RAT). Proje, modüler yapısı ve esnek yönetim araçlarıyla sistem yönetimi süreçlerini iyileştirmek için geliştirilmiştir.

SkyShell is a professional Remote Administration Tool (RAT) designed to monitor and manage remote computers over a secure, encrypted connection. The project is built with a modular architecture and flexible management tools to streamline system administration workflows.

> Developed by **Aury**

---

### 🛠 Dahil Edilen Modüller / Included Modules
*   **Eklenti Sistemi / Plugin System:** Komut gönderip almak için modüler altyapı. Modular infrastructure for sending and receiving commands.
*   **Erişim Terminali / Access Terminal:** İstemcileri kontrol etmek için geliştirilmiş yönetim konsolu. Advanced management console for controlling clients.
*   **Yapılandırılabilir İstemci / Configurable Client:** Terminal üzerinden uzaktan yönetilebilir istemci mimarisi. Client architecture that can be remotely managed via terminal.
*   **Log Sunucusu / Log Server:** Önemli tüm sistem olaylarını takip eden günlük kayıt sistemi. Logging system that tracks all significant system events.

### ✨ Temel Özellikler / Key Features
*   **Görüntüleme / Display:** Uzak masaüstü izleme, ekran görüntüsü alma ve canlı kayıt. Remote desktop monitoring, screenshot capture and live recording.
*   **Dosya Yönetimi / File Management:** SFTP üzerinden güvenli dosya yükleme, indirme ve yönetimi. Secure file upload, download and management over SFTP.
*   **Sistem Kontrolü / System Control:** Süreç yöneticisi, uzaktan kamera erişimi ve sistem süreç yönetimi. Process manager, remote camera access and system process management.
*   **İletişim / Communication:** İstemci ve sunucu arasında doğrudan sohbet penceresi. Direct chat window between client and server.
*   **Güvenlik / Security:** SSL/TLS şifreli bağlantı, anti-analiz koruması ve bütünlük denetimi. SSL/TLS encrypted connection, anti-analysis protection and integrity checks.
*   **Gelişmiş Araçlar / Advanced Tools:** Yerleşik Binary Builder, Obfuscator ve çoklu port dinleme desteği. Built-in Binary Builder, Obfuscator and multi-port listener support.
*   **Kurtarma / Recovery:** İstemci tarafındaki şifre kurtarma modülleri. Client-side password recovery modules.

### ⚙️ Teknik Detaylar / Technical Details
*   **Dil & Framework / Language & Framework:** C# (.NET Framework)
*   **Derleme / Build:** Visual Studio 2022 veya üzeri gereklidir. Visual Studio 2022 or above is required.
